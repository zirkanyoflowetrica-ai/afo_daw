MEZCLADOR AUTOMATICO V3.5 - AFINACION SUAVE

Cambios:
1. La afinacion se realiza como PRIMER procesamiento sobre la voz cruda.
2. Se elimina el renderizado independiente cada ~6 segundos.
3. Se procesa cada frase detectada en una sola pasada con contexto.
4. Se suaviza la curva de afinacion y se descartan saltos aislados de F0.
5. La union original/afinado se hace fuera de las notas vocales,
   en lugar de mezclar ambas fases durante las notas sostenidas.
6. Se conservan los formantes y las pistas no vocales no se afinan.
7. La ecualizacion, air, saturacion, compresion, mezclador, buses
   y masters se mantienen como antes.
8. Se incorporan las 5 pruebas del proyecto original y un test V3.5.

COMO EJECUTAR EN WINDOWS
- Descomprime el ZIP en E: u otra unidad con espacio suficiente.
- Ejecuta iniciar_windows.bat dentro de la carpeta extraida.
- Subes los stems y ajustas tonalidad/escala e intensidad.
- 0 desactiva afinacion. Prueba 40-65 para una correccion natural.
- 80-100 busca la nota exacta, pero aun puede cambiar el timbre
  de consonantes o frases con deteccion de F0 insuficiente.
- Usa pistas vocales secas: evita mezclar voz con beat dentro del stem.
- Revisa la comparacion A/B por pista, no solo el master.

LIMITACIONES
- No se ha validado la timbrica con una voz aislada real aportada.
- Procesar notas con Rubber Band puede introducir artefactos, incluso
  con curva suave. No es Auto-Tune comercial ni garantiza cero artefactos.
- Se ha probado en Linux de forma controlada; no se pudo iniciar
  una ventana en la instalacion local de Windows del usuario.
- Se conserva el RAR original sin modificar.
